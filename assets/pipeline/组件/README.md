# OutroTerminalSpoof · 终端报错欺诈流片尾

可复用片尾组件。在正片最后一帧上盖一层毛玻璃暗化遮罩，弹出一个赛博终端窗口，
用"系统权限拦截"的假故障包装"双击点赞"的引导。

## 结构：先给结果，再演过程（2.0 秒）

```
0.00 ─ 0.50   定格：完整页面      ← 观众先读全（首帧 = 尾帧）
0.50          交界面：整帧撕裂 + 青光闪一下（系统被打断）
0.53 ─ 1.03   日志逐字打印
1.03 ─ 1.43   边框转红 + 警告弹出
1.43 ─ 2.00   CTA 打出 + 黄底高亮 + 红心 + 品牌
```

为什么这么排：1.5 秒的片尾如果只在最后露出完整页面，观众根本来不及读，
一滑就走。把"结果页"提到开头定格 0.5 秒，读得到；动画照演；**结尾回到同一帧**，
所以还能无缝循环。

想改回原来的纯 1.5 秒：`--hold 0`
想改成"演完再定格"：`--hold-at tail`

## 交付物

| 文件 | 说明 |
|---|---|
| `outro_terminal.py` | 组件本体，零外部素材依赖（音效 numpy 现场合成） |
| `预览/24-片尾组件.mp4` | 2.0 秒成片，1080×1920 / 30fps / H.264 + AAC |
| `预览/25-片尾分镜.png` | 10 帧关键帧联系表（含交界处） |
| `预览/26-全片带片尾.mp4` | 264.3 秒正片 + 2.0 秒片尾 = 266.36 秒 |

## 三种用法

```bash
# 1) 只出组件（从视频最后一帧取底图）
python outro_terminal.py --base 05-成片.mp4 --out outro.mp4

# 2) 换文案（组件复用）
python outro_terminal.py --base 05-成片.mp4 --out outro.mp4 \
  --warning "> [错误] 检测到未关注用户，档案解密权限已冻结！" \
  --cta     "> 请立即【点个关注】重新授权，继续拆解 _" \
  --brand   "拆解师Ben · 沐杰架构"

# 3) 直接拼到正片末尾
python outro_terminal.py --attach 05-成片.mp4 --out 06-带片尾.mp4
```

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--warning` | `> [警告] 检测到白嫖行为，本地算力余额不足！` | 报错行 |
| `--cta` | `> 请立即【双击屏幕】注入点赞，完成档案签收 _` | 行动指令行 |
| `--log` | `> 正在为您归档本期【财富底牌图纸】...` | 日志行 |
| `--status` | `[ SYSTEM_INTERCEPT // MUJIE_ARCH_V2.6 ]` | 顶部状态条 |
| `--brand` | `拆解师Ben · 沐杰架构` | 右下角品牌 |
| `--highlight` | `双击屏幕` | 高亮词；**找不到时自动取【】里的内容** |
| `--hold` | `0.5` | 定格秒数；给 `0` 就是纯 1.5 秒版 |
| `--hold-at` | `head` | `head` 开头定格 / `tail` 结尾定格 |
| `--no-audio` | 关 | 不加音效 |

代码里对应 `OutroConfig` 数据类，配色、尺寸、圆角、遮罩浓度都在里面。

## 动画时间轴（相对动画段起点，固定 45 帧）

| 帧 | 秒 | 内容 |
|---|---|---|
| 0–1 | 0.00–0.07 | 交界故障：整帧撕裂 + RGB 色差 + 青光闪（只在从定格切进动画时出现） |
| 2–13 | 0.07–0.43 | 弹窗就位，日志逐字打印，带方块光标 |
| 14–26 | 0.47–0.87 | 边框转警告红（闪一次），警告行放大弹出；底部出现闪烁 `>` 提示符 |
| 27–45 | 0.90–1.50 | CTA 逐字打出 → 黄底黑字高亮 → 光标闪 → 红心呼吸 + 品牌角标 |

## 音效（合成，无版权风险）

音效会跟着定格自动后移 0.5 秒，不会出现"画面还没开始、声音先响"。

| 相对动画起点 | 声音 | 合成方式 |
|---|---|---|
| 0.00 | 电流切断 | 下滑正弦 420→40Hz + 噪声包络 |
| 0.12/0.19/0.26/0.33 | 机械键盘 4 声 | 噪声爆点 + 1.8k 以上正弦 |
| 0.50/0.585 | 警告 Beep-Beep | 方波 880 / 1174 Hz |
| 0.90 | 盖章 | 78Hz 下滑 thud + 咔哒 |

## 排版健壮性

- **折行**：中文按字断，英文只在单词边界断；最后一行不足 4 字自动从上一行回借，避免孤字
- **高亮兜底**：`--highlight` 的词不存在时，自动取第一个【】/『』/[] 里的内容
- **弹窗高度自适应**：文案变长自动加高，中心仍锁在画幅 45%
- **字体混排**：ASCII 走 Consolas Bold（等宽），中文走雅黑 Bold，逐字切字体，不出豆腐块
- **放大收敛**：警告行弹出时放大 1.12 倍，但会被内边距自动钳住，不会顶出边框

- 60 帧 / 2.000000 秒 / 1080×1920 / 30fps / H.264 yuv420p + AAC 48kHz 单声道
- 音效起点：0.50 / 0.69 / 0.83 / 1.00 / 1.39（与画面对齐）
- 音频峰值 -2.1 dBFS，不削波
- 拼接后 266.36 秒
- 自定义文案（含换行、无预设高亮词）渲染正常
