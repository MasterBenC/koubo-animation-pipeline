# 四种版式模式与选型

> 每支片子开工第一件事：**定模式**。模式定错，后面全白做。
> 判据不是"我喜欢哪种"，是**这条素材拍成了什么样**。

---

## 一、四个模式

| | 右下角画中画 | 人与动画互切 |
|---|---|---|
| **竖屏 9:16** | `portrait/corner` ✅ 已验证 | `portrait/cut` 几何已定，状态机待实现 |
| **横屏 16:9** | `landscape/corner` 等模板 | `landscape/cut` 等模板 |

配置在 `layout.py` 的 `PROFILES` 里，切换：

```bash
set LAYOUT_PROFILE=portrait/cut          # Windows
export LAYOUT_PROFILE=portrait/cut       # bash
```

```python
import layout as L
L.activate("portrait/cut")
```

选到还没定的模式会直接抛 `NotImplementedError` 并列出可用项，不会静默出错。

## 二、选型判据（按顺序问自己）

### 第 1 问：手在不在画面里说话？

| 观察 | 结论 |
|---|---|
| 半身/全身，手在比划、指东西、做手势 | **互切**。手是表达的一部分，缩进 280px 的圆里全废 |
| 胸像，肩膀以下没信息，手不出现 | 继续第 2 问 |

### 第 2 问：背景干不干净？

| 观察 | 结论 |
|---|---|
| 背景乱、有道具、有架子、有屏幕、有人走动 | **互切**。塞进小圆就是一团噪点 |
| 纯色墙 / 虚化 / 干净书架 | 继续第 3 问 |

### 第 3 问：这支片子靠什么推进？

| 观察 | 结论 |
|---|---|
| 图表、数据、结构图占大头，要看清细节 | **互切**。全屏动画能用满高度 |
| 金句多、靠表情语气、需要"有人陪着你"的感觉 | **右下角**。人一直在场 |

### 第 4 问：平台？

| 平台 | 倾向 |
|---|---|
| 竖屏信息流（抖音/视频号/小红书） | 右下角——留人比留画面重要 |
| 横屏知识区（B 站/YouTube/课程） | 互切——信息密度优先 |

> 前 3 问有任意一个是"互切"，就选互切。**只有全部指向右下角时才用右下角。**
> 因为互切是"信息优先"，右下角是"陪伴优先"；宁可多给信息，也不要让人看不清。

## 三、拍完先花 5 分钟自检

不是所有素材都能做右下角。拍之前/拍完先确认：

- [ ] 人脸始终在画面上 1/3（别飘到边上去）
- [ ] 头部上下留白够（头顶别贴边，否则裁成圆会切头发）
- [ ] 眼睛大致在画面上半部
- [ ] 机位固定（互切模式下尤其重要——人一会儿大一会儿小会像跳切）
- [ ] 光稳定（小圆里光一变特别明显）
- [ ] 背景在圆里不会突然出现移动物体

做不到的，**换互切**。互切不挑构图，只挑机位稳定。

## 四、各模式的参数

### portrait/corner（竖屏 + 右下角圆头像）✅ 已验证

| 项 | 值 |
|---|---|
| 画布 | 1080×1920 |
| 内容区 | x 72–1008，y 400–1290（936×890） |
| 字幕带 | y 1300–1460 |
| 圆头像 | 直径 280，圆心 (840,1555)，右距 100，下距 345 |
| 头部裁剪 | 520×520 @ (570,838) |
| 白边 / 羽化 / 阴影 | 2px / 10 / (0,10) 模糊 22 |
| 转场 | 全屏矩形 → 圆（0.7s 缩，0.55s 回） |

适合：胸像、背景干净、金句型内容、竖屏信息流。

### portrait/cut（竖屏 + 互切）⬜ 几何已定

| 项 | 值 |
|---|---|
| 画布 | 1080×1920 |
| 内容区 | x 72–1008，**y 220–1290**（936×1070，比 corner 高 180px） |
| 字幕带 | y 1300–1460（不变） |
| 人物 | 全屏原样，不裁不缩 |

**还差状态机**——下面是待定的规则，定了才能用：

1. **切点放哪？** 建议按句切（一个 `cues.json` 的 cue 一切），不要按秒切
2. **怎么进怎么出？** 三个候选：
   - 硬切（最干净，但最跳）
   - 0.2s 推镜（人物轻微推近，观感柔）
   - 沿用 corner 的"缩成圆再展开"（前后统一，但就没意义了——那就该用 corner）
3. **人物全屏时要叠东西吗？** 建议不叠，纯人物；叠了就不是"互切"了
4. **机位要求**：必须固定。人一会儿大一会儿小，观众会以为视频卡了

### landscape/*（横屏）⬜ 等模板

横屏有个关键差异：**横屏几乎不用圆形头像**。16:9 上放个 280px 的圆会被读成贴纸。
横屏通常用**圆角矩形卡片**，放左下或右下，占画面高 40–55%，带投影贴边。

所以 `landscape/corner` 不是"圆的横屏版"，是**另一种元素**（卡片 vs 圆）。
参数（安全区、字幕带、卡片尺寸、内容区）等用户给模板再定。

## 五、模式与后面的所有事

选定模式后，**这四件事全都要跟着变**：

| 环节 | 受什么影响 |
|---|---|
| 版式参数 | 内容区大小、字幕带位置、画中画形状 |
| 场景设计 | 内容区高度差 180px（corner 890 vs cut 1070），同样的图表排法不一样 |
| 验收标准 | `check_layout.py` 的圆侵入检查在 cut 模式下没有意义 |
| 合成路径 | corner 每帧合成两层；cut 是拼接，不做逐帧合成 |

所以**模式必须一开始就定死**，中途换等于重做。

---

## 六、给新片子的建议顺序

1. 先看素材 → 按第二节四问定模式
2. 跑 `install.py` 装工具链
3. 改 `layout.py` 只改**该模式的参数块**，别动别的模式
4. 跑一遍 `check_layout.py`（cut 模式下圆检查会自动跳过）
5. 再开始写场景

横屏模板到位后，补 `landscape/corner` 和 `landscape/cut` 两组参数，其余流程不变。
