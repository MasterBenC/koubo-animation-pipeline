## 一句话流程

```
原片 → ASR → 剪辑决策(EDL) → 粗剪 + timemap → 复转比对 → 台词表(cues)
     → 超分 → 定版式 → 逐场动画 → 渲染片段 → 合成 + 响度 → 六道验收 → 交付（字幕用户自己烧）
```

工作量参考：ASR 10 分钟 / 剪辑决策 1 小时 / 16 场动画 2–3 天 / 渲染合成 20–40 分钟。

## 落地命令（最短路径）

```powershell
# 0) 装工具链 / 建新片（在 skill 目录跑）
python <skill>\install.py --root "<工作区>" --name <项目> --title "<标题>"

# 1) ASR
python "<工作区>\管线\scripts\transcribe.py" "<项目>\01-原片\raw.mp4" -o "<项目>\01-asr" --lang zh

# 2) 剪辑链（顺序不能换）
python "<工作区>\管线\scripts\build_edl.py" "<项目>\02-剪辑\cuts.json" -o "<项目>\02-剪辑"
python "<工作区>\管线\scripts\cut.py" --input "<项目>\01-原片\raw.mp4" `
  --segments "<项目>\02-剪辑\segments.json" --out "<项目>\02-剪辑\02-粗剪.mp4" `
  --timemap "<项目>\02-剪辑\timemap.json"
python "<工作区>\管线\scripts\transcribe.py" "<项目>\02-剪辑\02-粗剪.mp4" -o "<项目>\02-剪辑\asr_verify"
python "<工作区>\管线\scripts\build_cues.py" "<项目>\02-剪辑\asr_verify\words.json" `
  -o "<项目>\02-剪辑\cues.json" --dump

# 3) 超分
ffmpeg -y -i "<项目>\02-剪辑\02-粗剪.mp4" -vf "scale=1080:1920:flags=lanczos,unsharp=5:5:0.5:5:5:0" `
  -c:v libx264 -crf 16 -preset medium -pix_fmt yuv420p -c:a copy "<项目>\02-剪辑\03-超分.mp4"

# 4) 定版式（只改 layout.py 的 PROFILES 块）→ 出构图验收图
python "<项目>\03-动画\make_check_png.py" <成片帧.png> "构图验收.png"

# 5) 写场景（每场 frame(t)，ts = L.lead(t)，标题层 K.scene_head）
#    写完立刻跑 ①②③④⑥
cd "<项目>\03-动画"
python check_layout.py s07 --step 0.5
python check_text.py s07 --fps 10
python audit_band.py s07
python audit_canvas.py s07
python audit_text_band.py s07

# 6) 渲染 + 合成 + 响度
python build_clips.py --force --jobs 4 --crf 17
python compose_final.py --out "..\02-剪辑\04-合成.mp4"
ffmpeg -y -i "..\02-剪辑\04-合成.mp4" -af "loudnorm=I=-14:TP=-1.0:LRA=11" `
  -c:v copy -c:a aac -b:a 192k -ar 48000 -movflags +faststart "..\02-剪辑\05-成片.mp4"

# 7) 六道验收全绿，再出字幕
python audit_timing.py
python "<工作区>\管线\scripts\make_srt.py" --proj "<项目>" -o "<项目>\final.srt" --max-chars 18
```

## 三条最容易忘的

1. **字幕不烧**：成片 mp4 里不许有字幕像素，ffmpeg 禁用 `subtitles=` / `ass=` / `drawtext=`。
2. **画面领先台词**：`ts = L.lead(t)`（+0.12s），绝不是 `t -= 0.12`。
3. **响度用 loudnorm**，不要抄 `volume=7.2dB`——那是某一条素材的差值。
