# 案例回灌 · EP.03 / EP.04（2026-11，两条竖屏成片）

> 这一版（0.3.0）的改动全部来自同一条产线上的两个真实片子：
> **EP.04「卢特尼克」**（336.6 s / 21 场 / 153 句）和 **EP.03「黄仁勋·上集」**（326.1 s / 18 场 / 87 句）。
> 两条都是 1080×1920 / 30 fps / −14 LUFS、字幕不烧、右下圆头像。
> 写在前面：**下面的「用户口径」是原话或原话的直接结论，不是我的总结。**

## 1. 画面里的字：从「全删」到「只标题」

这是这一版最大的一条，因为来回改了两轮：

1. 第一轮用户说「把 EP03 这些字删掉」→ 我把标题/数字/年份/印章/人名全删，做成纯图版。
   **用户真实意思是"删画面里的字"，不是"删项目"**——这条差别让我误删过 0.94 GB（见 §3）。
2. 第二轮用户说「还是要有点文字的，要不然太单一」→ 定稿成**只保留标题层**。

定稿的标题层（`kit_clean.scene_head`）：

| 项 | 值 |
|---|---|
| 结构 | 每场**一行标题**（微软雅黑 Bold 44 / 米白）+ **一句副标**（25 / 冷灰），可选 |
| 落区 | 只在 y 254–360 的空带；内容区 400–1290、**字幕带 1300–1460 一像素不碰** |
| 可读性 | 顶部 y 0–470 压一层深色渐隐薄膜（`scrim_top`），照片底上也能读 |
| 装饰 | 左侧 5 px 琥珀竖条，入场时从上往下长出来 |
| 入场 | 每场 `t_in=0.30`、0.55 s 淡入；标题垫一层 55% 黑影，副标入场时轻微上浮 |
| 开关 | `EP03_TEXT=mid`（默认，标题+副标）/ `light`（只标题）/ `off`（回纯图） |
| 文案 | 场景生成脚本里的一个 `TEXT = {场景名: (标题, 副标)}` 字典，一行一场 |

结论：**竖屏口播的画面文字是"导航"，不是"字幕"**。一屏超过「1 个主信息 + 1 条副信息」就该删；
但一屏都没有字，观众会觉得"这集是不是没做完"。

## 2. EP.04 给的另一条反面经验：底要换

用户对 EP.04 的要求是「跟上一集一样」——同一套大字体系，但**背景要四种底轮换**
（国会山实拍 / 聚光黑底 / 双色章节 / 航线点阵），连续两场不许同一种。
一条 5 分半的片子 21 场，如果底只有一种，观众 90 秒就开始疲劳。
所以排版式时要先排「底的序列」，再往里填内容。

## 3. 一次不可逆的事故（写进铁律）

用户说「把那个 EP03 都删掉吧」。我理解成"删整个项目"，`Remove-Item -Recurse` 删掉
500 个文件 / 0.94 GB，**回收站没进**。用户真实意思是"把视频里的字删掉"。

- 恢复：误删前留的 `_archive/` 备份救回了原片、`final.srt`、`cues.json`、事实核对；
  四个历史成片和全部场景源码**永久丢失**，只能重写。
- 现在的规则：**破坏性指令先复述一遍"我要删的是 X，不是 Y"，等用户确认再动手。**

## 4. 实测参数（可以直接抄）

| 项 | 值 |
|---|---|
| 头部裁切（EP.03 本片实测） | `box=980 @ (590,932)`（默认 520×520 @ (570,838) 装不下这个机位） |
| 圆头像 | 直径 280，圆心 (840,1555)（右距 100 / 下距 345） |
| 内容区 / 字幕带 | x 72–1008 / y 400–1290；字幕带 y 1300–1460 |
| 画面延迟 | 每场 `frame(t)` 先 `t -= 0.12`（画面比台词略晚一点点） |
| 单帧渲染 | 缓存做好后 ~50 ms；不做缓存 1.5 s（20–30 倍差距） |
| 渲 18 场 | 10 min（`--jobs 4`，CRF 17，含标题层） |
| 合成 324 s | 23 min（本机空闲时 11–20 min，开视频会议能拖到 90 min） |
| 成片 | 326.10 s / 51.3 MB / −14.00 LUFS / TP −1.17 |

## 5. 新增的第六道验收

`assets/pipeline/成片/_模板/03-动画/audit_text_band.py`：把每场按 1 fps 跑一遍，检查**每一个文字包围盒**
都落在 y 140–1290 / x 60–1020 内。它抓的是「标题排到字幕带里」「副标顶出画布右边界」这类
肉眼在小图上看不出来的错。EP.03 18 场跑下来 0 越界，才敢渲。

用法：

```bash
cd 03-动画
python audit_text_band.py            # 全部场景
```

## 6. 素材与研究（这两条片子踩得最疼的地方）

- **人物肖像**：Bing 图片搜索大量串词（返回米老鼠剪纸、蜘蛛侠服装），
  人物图必须过 vision 复核；宁可上"首字母灰卡"，也不要配错人——那是"配图即指控"。
- **来源不可达**：NYT / Seattle Times / Al Jazeera / NBC / AP / Guardian / Truth Social
  在本机连不上（TCP 超时），截图永远抓不到；改用授权转载站（thestar / investing.com / CNBC）
  并保留出处。
- **一手来源**：画面里的"谁干的/哪一天/多少钱"必须能点开原文；报道口径写「据……报道」；
  查不到的不上屏。EP.03 口播里有 4 处归因错误，画面按**修正后**的口径写，字幕留给用户决定。
- **图不能裁**：用户的硬口径是"背景图必须看全"，`photo_card` 一律 `contain`，不裁切。

## 7. 还没解决的

- **词级字幕**：现在只有句级时间轴，长句字幕会偏半句；要准只能上 ASR 词级或 TTS 时间戳。
- **BGM / SFX**：本系列口径是"不加 BGM"，`sfx_build.py` 还是空的（泼冷水低频、铁柜落地、glitch tick 都没做）。
- **模板 vs 项目代码**：`kit_clean` / `hud` 这类每片重写的零件，应该收成 `scene_kit` 的可选模块，
  否则第三个片子还要再写一遍。
