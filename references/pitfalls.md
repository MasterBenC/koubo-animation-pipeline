# 坑位清单（全部真实踩过）

> 开工前读一遍。这些坑每一条都花过至少半小时。

---

## 渲染

1. **PIL 的 `ImageDraw` 在 RGBA 画布上不混色**，是直接覆盖像素、顺手改 alpha。
   表现：淡入变硬切、空进度条画出来是满的、30% 白的填充变实心、
   背景网格行上多一条亮线。
   解法：`motion.Canvas` 在**不透明底图上渲染成 RGB**，透明元素统一走 `_comp()` 混。
   场景里不要直接 `c.img.alpha_composite(...)`。

2. **`Image.filter(GaussianBlur)` 会把整张图糊掉**。
   做圆头像羽化时糊了整张卡片，220px 的圆里脸是虚的。
   羽化只能作用在**蒙版的 alpha** 上，不能作用在已经合成好的画面上。

3. **超采样 2x 再缩回**，文字边缘才干净。1x 直接画中文会毛。

4. **每帧都重建大对象会拖慢**。渐变、蒙版、阴影都要缓存（按尺寸做 key）。
   但**缓存 key 要带上所有变量**——羽化量变了而 key 没变，会取到旧图。

## 版式

5. **落边元素不要正好压在边界上**。PIL 抗锯齿溢 1–2px，检查脚本判失败。内缩 4–6px。

6. **头像裁切框按单帧测量必翻车**。人说话会挪 100+ 像素。
   必须扫多个时间点取并集（见 `layout-rules.md` 第二节）。

7. **`to_full` 过渡要传 `1 - prog`**。传 prog 会导致「先缩成圆、最后一帧硬跳全屏」。

8. **场景里的私有辅助函数可能绕过了画布封装**。
   画布改成 RGB 之后，`c.img.alpha_composite()` 和 `dst.getchannel("A")` 这类
   直接操作会崩（`image has wrong mode` / `no channel "A"`）。
   改画布模式后，**16 场都要跑一遍**才知道哪里炸。

---

## 时间

9. **不要先写动画再对时间**，一定先列台词表再挂元素。

10. **画面静止 6 秒 = 观众划走**。讲重点时画面不能停。
    自查：`audit_timing.py <场次> --thresh 60`，看最后一条事件离结尾多远。

11. **`-shortest` 会按最短的流剪画面**。给片尾加定格后，音效还是原长度，
    结果 60 帧被剪回 45 帧。**音效长度必须等于总时长**。

12. **音效要跟着画面位移**。定格在开头时，音效整体也要后移，
    否则会出现「画面还没开始、声音先响」。

## 工具链

13. **`curl.exe` 在受限沙箱里连不上 HTTPS**（`SEC_E_NO_CREDENTIALS`）。
    出站请求用 Python 的 `urllib`。

14. **PowerShell 的双引号 here-string (`@"..."@`) 会解释反引号转义**：
    - `` `n `` 真换行、`` `t `` 制表符、`` `f `` **换页符**（吃掉后面的 f）、
      `` `a `` **响铃符**（吃掉后面的 a）
    - 写文档时正文里的反引号（Markdown 行内代码）会被误伤，
      典型症状：「final.srt」变「inal.srt」、「ass=」变「ss=」
    - **解法：正文带反引号或多行内容，一律写成 .py 文件用 `Path.write_text` 落盘，
      不要在 PowerShell 里拼字符串**
    - 出问题后用 `[c for c in s if ord(c)<32 and c not in "\n\r\t"]` 扫一遍控制字符

15. **OpenCV 5.0 移除了 `CascadeClassifier`，且新 ONNX 导入器读不了 YuNet**
    （`Can't read ONNX file`，ASCII 路径也一样）。另外 **cv2 在中文路径下打不开文件**。
    → 头部标定用手动网格法，别依赖 `measure_head.py`。

16. **`build_clips.py` 的参数是场景 ID**（`S07 S11`），不是文件名；**没有 `--only` flag**。

17. **ffmpeg 的 concat 列表带 BOM 会报 `unknown keyword 'file'`**。
    用 `UTF8Encoding($false)` 写。

18. **多个子 agent 同时改同一个文件会互相覆盖**。
    派活前确认目标文件没被占用；同时改同一场景会得到半新半旧的代码。

## 协作

19. **「再大一点」「往下一点」这类反馈，不要靠猜**。
    一次渲染 3 档真图给他选。光圆头像位置就来回改了 4 轮，
    改成「一次给 3 档」后一轮就定了。

20. **子 agent 说「完成了」不等于完成**。必须自己跑一遍验收命令、读一遍静帧。
    有子 agent 在报告阶段崩掉但文件其实已经改好的情况，
    也有改到一半崩掉留下坏文件的情况——都要自己复核。
